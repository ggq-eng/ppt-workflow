# ppt-workflow

> 来源分类：**待确认** ｜ 导出批次：review

基于标准化工作流的 PPT 制作技能。从内容搜索到美化优化的全流程自动化。只需提供主题，自动完成文献搜索、框架设计、内容填充、幻灯片制作、美化优化和输出交付。

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/ppt-workflow        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/ppt-workflow   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
